# 지출 건 도우미 (GIST Expense Helper)

연구비 증빙 파일을 넣으면 업체·금액·날짜·품목을 자동 인식하고,
규칙에 맞게 **폴더 생성 → 파일명 변경 → 구글시트 등록 → 결재 제목 복사**까지 한 번에 처리하는 Windows 프로그램입니다.
토큰(AI)을 쓰지 않는 규칙 기반 프로그램이며, 내부 자료(시트 주소·업체 정보)는 코드에 포함하지 않고 업무 PC에만 저장됩니다.

## 설치 순서 (처음 1회)

### 1. 구글시트 연결 (약 5분)
1. 연구비 시트 열기 → 메뉴 **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 `apps_script/Code.gs` 내용을 붙여넣기 → 저장
3. 위쪽 함수 선택에서 `setup` 선택 → **실행** → 권한 허용
4. 아래 **실행 로그**에 나온 `연결키` 복사
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
6. 배포 후 나오는 **웹 앱 URL** 복사

> 연결키가 없으면 시트에 쓸 수 없으므로, URL이 알려져도 연결키 없이는 수정되지 않습니다.

### 2. 프로그램 실행
1. [Releases](../../releases/latest)에서 `GistExpenseHelper.exe` 내려받기
2. 실행 → **설정** 화면에서
   - 상위 폴더 선택 (과제·비목 폴더 자동 생성)
   - 웹 앱 URL과 연결키 입력 → **연결하고 설정 불러오기**

## 사용
- **새 건 등록**: 증빙 파일을 끌어다 놓기 → 과제·세목 선택 → 인식 결과 확인 → 저장
- **진행 대시보드**: 건별 ZEUS·이지바로·진행상황 선택 → 적용 (시트 반영 + 폴더명에 `(진행중)`/`(완)`)

## 이름 규칙
| 대상 | 형식 |
|---|---|
| 건 폴더 | `과제\번호_비목\YYMMDD_업체_품목(금액원)` |
| 파일 | `(서류종류) [과제번호] 예산항목-업체_품목(YYMMDD).pdf` |
| 결재 제목 | `[과제번호] 예산항목(YYMMDD)_업체 품목` |

## 업데이트
실행할 때마다 새 버전을 확인하고, 있으면 화면 위에 **지금 업데이트** 버튼이 표시됩니다.
개발 측은 `app/version.py`의 버전을 올리고 main 브랜치에 푸시하면 GitHub Actions가 exe를 자동 빌드해 릴리스합니다.

# 블로그 자동 작성기 (MazziBlogUploader)

원고 폴더(final.md + 사진·GIF·동영상)를 고르면 네이버 스마트에디터에 **직접 입력**해 **임시저장**까지 진행합니다. 발행은 하지 않습니다.

- 붙여넣기 없이 한 글자씩 입력, 색·크기·굵게·형광펜은 에디터 툴바로 적용
- 사진·GIF·동영상·지도·구분선·인용구는 에디터 버튼으로 삽입
- 전용 크롬 창을 내부 명령으로 조작 → 마우스·키보드를 점유하지 않음 (창 최소화 가능)
- 처음 한 번 열린 크롬 창에서 네이버 로그인 필요 (비밀번호는 저장하지 않음)
- 결과: 글 폴더 `out/upload_log.txt`, `out/upload.png`, 실패 시 `out/fail_N.png`

## 원고 서식 (final.md)
| 표기 | 결과 |
|---|---|
| `제목: ...` `커버사진: cover.jpg` | 제목칸, 커버 |
| `## 소제목` | 19pt 굵게, 색 자동 순환 |
| `**굵게**` | 굵게 |
| `{노랑:텍스트}` `{연핑크:}` `{민트:}` `{하늘:}` `{살구:}` `{연보라:}` | 형광펜 |
| `{핑크글자:}` `{파랑글자:}` `{보라글자:}` `{초록글자:}` `{주황글자:}` | 글자색 + 굵게 |
| `[사진: 01.jpg]` `[사진: A.jpg, B.jpg 나란히]` `[GIF: g01.gif]` | 사진 |
| `[동영상: video.mp4|동영상 제목]` `[지도: 장소명]` `[구분선]` | 컴포넌트 |
| `[인용구 시작]` ~ `[인용구 끝]` | 인용구 (A 줄 숫자 자동 노랑) |
| 마지막 `#태그 #태그` 줄 | 해시태그 |

네이버가 에디터 화면을 바꾸면 `blog/selectors.json`만 고치면 됩니다. 프로그램이 실행할 때마다 최신본을 받아 씁니다.
